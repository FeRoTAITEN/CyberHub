===============================================
A) AUTHENTICATION & GENERAL STANDARDS
===============================================
- Auth: Bearer token (preferred) or API Key
  Header: Authorization: Bearer <token>
- Base URL: To be provided by IT (e.g., https://api.company.com)
- Formats: JSON UTF-8
- Dates: YYYY-MM-DD for daily ops; ISO 8601 for DateTime
- Time: HH:MM (24h)
- Pagination: limit, offset (please support)
- Rate limits: please specify
- Errors: { success: false, error: string, details?: object }
- Arabic fields: Optional with _ar suffix
