        SOC INTEGRATION - IT ENDPOINTS REQUEST

Project: CyberHub - SOC (Shift Management)
Audience: Company IT (API Providers)

===============================================
A) AUTHENTICATION & GENERAL
===============================================
- Auth: Bearer token (preferred) or API Key
  Header: Authorization: Bearer <token>
- Base URL: To be provided by IT (e.g., https://api.company.com)
- Formats: JSON UTF-8
- Dates: YYYY-MM-DD for daily ops; ISO 8601 for DateTime
- Time: HH:MM (24h)
- Pagination: limit, offset (please support)
- Rate limits: please specify
- Errors: { success: false, error: string, details?: object }

===============================================
C) ENDPOINTS REQUIRED (WRITE)
===============================================
1) Manual Assignment
POST /shifts/assign
Request:
{ "date": "2025-01-12", "shift_id": 1, "employee_id": 101, "assigned_by": 1 }
Response: { "success": true, "assignment": { ... } }

2) Remove Assignment
DELETE /shifts/assignments?id=555
Response: { "success": true }

3) Add Availability (Apology)
POST /shifts/availability
Request:
{ "employee_id": 101, "date": "2025-01-15", "reason": "Leave", "reason_ar": "إجازة", "notes": "", "created_by": 1 }
Response: { "success": true, "id": 10 }

4) Assign Pattern to Employee
POST /employees/pattern
Request:
{ "employee_id": 101, "pattern_code": "alpha" | null }
Response: { "success": true }

5) Auto-Schedule (server-side action)
POST /shifts/auto-schedule
Request (month): { "year": 2025, "month": 1, "mode": "month", "patterns": ["alpha"], "assigned_by": 1 }
Request (quarter): { "year": 2025, "month": 1, "mode": "quarter", "patterns": ["alpha"], "assigned_by": 1 }
Request (year): { "year": 2025, "mode": "year", "patterns": ["alpha"], "assigned_by": 1 }
Response: { "success": true, "createdCount": 120, "rangeStart": "2025-01-01", "rangeEndExclusive": "2025-04-01" }

6) Clear Schedule
POST /shifts/clear-month
Request (month): { "year": 2025, "month": 1 }
Request (quarter): { "year": 2025, "month": 1, "mode": "quarter" }
Request (year): { "year": 2025, "mode": "year" }
Response: { "success": true, "deletedCount": 90 }
